💻 System Requirements & Azure VM Install ▼

System Requirements (Azure Windows VM)

ComponentMinimum
Azure VMB1s (1 vCPU, 1GB RAM)
OS ImageWindows Server 2019+ (Azure Marketplace)
Python3.8+ (download from python.org)
Disk (C:)30GB — standard OS drive
Disk (baselines)~50KB each — just a folder on C:
Network/NSGRDP (3389) for admin, app on localhost:8000

Where Baselines Are Stored

JSON files in a folder on the C: drive. Default:
C:\vet-sql-tester\baselines\
Just a normal Windows folder — survives reboots, stays on the C: drive. If the VM gets rebuilt, copy the baselines folder first or point VET_BASELINE_DIR to a D: drive (Azure data disk).

Install Steps (RDP into Azure VM)

1. Install Python 3.11 from python.org Check "Add Python to PATH" 2. Create folder: C:\vet-sql-tester\ Create subfolder: C:\vet-sql-tester\baselines\ 3. Copy app files (app.py, app.yaml, requirements.txt, data_generator.py, templates\index.html) into C:\vet-sql-tester\ 4. Open Command Prompt: cd C:\vet-sql-tester pip install flask pyodbc # pyodbc for SQL Server 5. python app.py → open http://localhost:8000 in browser

Desktop Shortcut (standalone app)

1. Create a batch file: C:\vet-sql-tester\start.bat Contents: @echo off cd /d C:\vet-sql-tester set VET_BASELINE_DIR=C:\vet-sql-tester\baselines python app.py 2. Right-click start.bat → Send to → Desktop (create shortcut) 3. Right-click the shortcut → Properties: → Change icon → pick any .ico you like → Rename to "Vet SQL Tester" 4. Double-click to launch → opens http://localhost:8000 Tip: Copy the shortcut to: C:\Users\%USERNAME%\AppData\Roaming\Microsoft\Windows\ Start Menu\Programs\Startup\ to auto-launch when you log in.

Production Mode (SQL Server on VM)

Edit run_query_on_db() in app.py to connect to your real SQL Server database. Use pyodbc with ApplicationIntent=ReadOnly in the connection string. Data stays on the VM — designed to keep everything local.
